# Clash-of-Clans——策略塔防游戏

## 简介 (Introduction)
本项目是一个基于 Cocos2d-x 引擎开发的策略塔防类游戏。玩家扮演村庄的首领，通过建设村庄、生产资源、训练军队，来抵御外敌或主动出击挑战不同难度的关卡。游戏融合了模拟经营与即时战略（RTS）元素，拥有完整的建筑升级、兵种战斗、录像回放及战绩统计系统。

## 游戏特色 (Features)

### 1. 村庄建设 (Village Management)
*   **资源循环**：通过**金矿**和**圣水收集器**持续生产资源，并存储在**储金罐**和**圣水瓶**中，用于后续的建设与训练。
*   **建筑体系**：
    *   **核心**：大本营 (Town Hall) - 村庄的心脏。
    *   **军事**：兵营 (Barracks) 提升人口上限，训练营 (Training Camp) 产出士兵。
    *   **防御**：加农炮 (Cannon)、箭塔 (Archer Tower) 负责远程与近程防御，隐形炸弹 (Landmine) 提供陷阱伤害，城墙 (Wall) 延缓敌人进攻。
*   **自由布局**：支持在网格地图上自由拖拽放置建筑，具备防重叠检测功能。

### 2. 战斗系统 (Combat System)
*   **三大难度**：提供简单 (Simple)、中等 (Medium)、困难 (Hard) 三级挑战，敌方防御布局逐级增强。
*   **四大兵种**：
    *   **野蛮人 (Barbarian)**：近战肉搏，均衡型单位。
    *   **弓箭手 (Archer)**：远程射击，可隔墙攻击。
    *   **炸弹人 (Bomber)**：针对城墙有极高伤害，用于开路。
    *   **巨人 (Giant)**：高生命值坦克，优先攻击防御建筑。
*   **策略投放**：战斗时需在村庄外围（红色警戒线外）合法区域投放兵种，考验玩家的切入点选择。

### 3. 辅助系统 (System Features)
*   **回放系统 (Replay)**：自动记录战斗过程，随时重温经典战役。
*   **战绩历史**：主界面可查看过往战斗的胜负记录与详细数据。
*   **沉浸体验**：包含主菜单、村庄、战斗三种场景的专属背景音乐 (BGM) 及丰富的战斗音效。

## 操作说明 (Controls)
*   **鼠标左键 / 触屏点击**：
    *   **建造/移动**：在村庄模式下，点击建筑图标进行建造；长按拖拽已建好建筑调整位置。
    *   **战斗投放**：在战斗模式下，先点击下方兵种卡片选中，再点击地图上的合法区域（非红色框内）生成士兵。
*   **界面交互**：
    *   点击右上角资源栏可查看当前存量。
    *   点击“Attack”进入选关界面。
    *   点击“History”查看对战记录。

## 开发环境 (Development Environment)
*   **引擎版本**：Cocos2d-x（v3.17)
*   **编程语言**：C++ 11/14
*   **构建工具**：CMake / Visual Studio

## 目录结构 (Directory Structure)
*   `Classes/`
    *   `scene/`：包含 `MainMenuScene` (主菜单), `VillageScene` (主场景), `BattleScene` (战斗场景)
    *   `building/`：包含各类建筑的逻辑实现 (`TownHall`, `Cannon`, `GoldMine` 等)
    *   `soldier/`：包含士兵行为逻辑与AI (`Soldier`)
    *   `core/`：通用工具类与网格系统
*   `Resources/`：存放所有的纹理图片 (.png)和音效音乐 (.mp3)
